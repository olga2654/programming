## Навіщо вивчати системи контроля версій Git і GitHub?

За допомогою систем контроля версій ти зможеш працювати з проєктом локально і на віддаленому репозиторії, вносити зміни, робити коміти і відображати проєкт на Github Pages. А також, працювати з командним проєктом створюючи гілки та вирішуючи конфлікти під час злиття гілок.

## Під час курсу ти:

- дізнаєшся основні команди Git і їх призначення
- навчишся створювати локальні і віддалені репозиторії
- зможеш через термінал відкривати проєкт у VS Code
- дізнаєшся, як вносити зміни у проєкт та створювати коміти
- зможеш тимчасово зберігати зміни за допомогою stash
- навчишся відправляти зміни на Github
- навчишся робити налаштування GitHub Pages в репозиторії
- створюватимеш і змінюватимеш локальні і віддалені гілки
- навчишся працювати з pull requests
- дізнаєшся, як вирішувати конфлікти злиття у проєкті
